# MCP tool reference

_Generated by `npm run docs:tools` from `mcp-server/`. 74 tools. **Bold** arguments are required._

Every tool is available three ways: over MCP (stdio, `mcp-server/index.mjs`), over HTTP as `POST /api/<tool_name>` with a JSON body, and to the in-app agent.

## Folders & categories

| Tool | What it does | Arguments |
|---|---|---|
| `list_categories` | List the fixed enum of life categories. | — |
| `list_epics` | List all epics under data/epics/, optionally filtered by category and/or agent owner. | category, agent |
| `get_epic` | Fetch a single epic. Returns frontmatter, full epic.md body, and the issue list. | **slug** |
| `append_to_epic` | Append a bullet to a section in an epic's epic.md. | **epic**, **section**, **line** |
| `update_epic` | Patch an epic's frontmatter (title, agent_owner, related_epics, category, short_slug) and/or replace its body content. | **slug**, **patch** |
| `delete_epic` | Permanently delete an entire epic — its folder, all issues, sub-issues, and arbitrary files. | **slug** |
| `create_epic` | Create a new epic. Creates data/epics/<category>/<slug>/ with epic.md + empty issues.md. | **category**, **slug**, **title**, agent_owner, body |
| `create_category` | Create a new (empty) top-level category folder under data/epics/. | **name** |
| `delete_category` | Permanently delete an entire top-level category folder (data/epics/<name>/) and EVERY epic, issue, sub-issue, and file inside it. | **name** |
| `list_epic_files` | List arbitrary files stored under an epic (in addition to epic.md / issues.md). | **epic** |
| `read_epic_file` | Read a file under an epic folder by name. | **epic**, **filename** |
| `write_epic_file` | Create or overwrite a file under an epic folder. | **epic**, **filename**, **content** |
| `append_epic_file` | Append content to an existing epic file (or create it if missing). | **epic**, **filename**, **content** |
| `delete_epic_file` | Remove a file from an epic folder. | **epic**, **filename** |
